# Проверки прототипа

Дата: 2026-10-04. Среда: Linux x86_64, Node.js 24.19.0.

## Выполнено

- Чистая установка `npm ci` по lockfile, production-сборка Vite и строгая проверка TypeScript
- 56 автоматических тестов: детерминированные логические тесты экономики, боя, наград, двух слоёв улучшений, паузы, сохранений и окончаний забега
- Полный автоматический прогон до победы над боссом на 15 контрольных seed; в постоянной регрессии seed 1, 3, 17, 42, 2026. Сохранение и загрузка между волнами на seed 42, дополнительно 1736 снимков за полный прогон
- Независимый обзор кода и исправление найденных проблем: повреждённый пустой save, покупки клавишами на экране результата, перехват пробела на кнопках

Точные актуальные числа тестов выводит `npm run check`. Workflow не публикует сборку при провале проверок.

## Пока не подтверждено

- Проверка настоящего WebGL-рендера в игровом браузере: облачный браузер отказал в доступе к локальному preview с ERR_BLOCKED_BY_CLIENT
- Проверка на физических телефонах, FPS на Android/iOS, 15-минутный GPU-прогон и пользовательский плейтест
- Деплой и проверка опубликованного URL не выполнены: исходный код подготовлен для предоставленного репозитория Mech-idle; требуется подтверждённый успешный workflow GitHub Pages

Логические тесты работают без WebGL. Их успешность не является свидетельством проверки GPU, касаний или FPS. Рендер использует инстансинг, ограниченные пулы эффектов, pixel ratio до 1.5 и не включает дорогие тени; фактические счётчики доступны через `SceneView.stats()` при runtime-проверке.
