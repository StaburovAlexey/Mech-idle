# ОПЛОТ — Турель и мехи

Играбельный 3D-прототип защиты неподвижной турели: 30 волн, случайные направления атак, три типа обычных мехов и финальный Колосс. Турель стреляет сама; игрок управляет улучшениями.

[Играть в браузере](https://staburovalexey.github.io/Mech-idle/) · [Репозиторий](https://github.com/StaburovAlexey/Mech-idle)

Авторы 3D-моделей: PolygonDan, Quaternius и tevy. [Источники и лицензии](ASSET_PROVENANCE.md).

## Запуск

Нужен Node.js 24 и npm.

```sh
npm ci
npm run dev
```

Откройте адрес Vite с путём `/Mech-idle/`.

```sh
npm run test    # логические регрессии, сохранения и паузы
npm run build   # строгая проверка TypeScript + production-сборка
npm run check   # все проверки
npm run preview
```

## Как играть

- Нажмите «Новый забег». Прицеливание и огонь автоматические
- За Штурма: 3 золота; за Рывка или Стрелка: 4; за Колосса: 50
- Четыре боевых модуля покупаются за золото: урон, максимальные HP, темп стрельбы и ремонт
- Купленный за золото модуль действует сразу, в том числе между волнами и на ручной паузе. Урон новых выстрелов меняется сразу; уже летящие снаряды сохраняют урон. Темп пропорционально сокращает оставшееся ожидание выстрела, без бесплатного выстрела
- Здоровье переносится между волнами. Покупка максимальных HP повышает потолок, но не лечит. Ремонт действует только во время боя и короткого перехода
- Каждая полностью пройденная волна даёт 1 кристалл. В мастерской кристаллы усиливают стартовые параметры будущих забегов
- Поражение и победа завершают забег. Золото и боевые модули сбрасываются; кристаллы и мастерская сохраняются
- На волне 30 появляется только Колосс. После его поражения наступает победа; волны 31 нет

Во время боя верхняя панель ресурсов и нижняя панель четырёх улучшений занимают отдельные строки. 3D-поле находится между ними: панели его не перекрывают. Кнопка «Меню» открывает управление, звук, правила, сохранение/выход и подтверждаемое завершение забега. Открытое меню останавливает бой; его закрытие не снимает отдельную ручную паузу.

Касания и мышь: кнопки интерфейса. Клавиши `1`–`4`: купить соответствующий модуль. `Пробел`: ручная пауза, когда фокус не на кнопке. `Escape`: открыть или закрыть меню боя; в диалоге отменяет закрытием. Кнопки поддерживают обычную клавиатурную навигацию. Звук включается отдельно кнопкой ♪ и генерируется в браузере.

## Сохранение и отсутствие

Снимок профиля и активного забега хранится одним объектом в localStorage этого браузера, вместе с проверенной предыдущей копией. Сохраняются RNG, враги, фазы атак, оба типа снарядов, покупки, дробные HP и оплаченные награды. Старые корректные снимки переходят на атаки с замахом однократно; оставшаяся перезарядка, валюты, HP и награды сохраняются, бесплатных ударов при загрузке нет. Перезагрузка открывает меню с кнопкой продолжения. Если старое сохранение содержит оплаченные, но ещё не включённые модули, при загрузке они включаются один раз, без повторной оплаты и лечения.

Скрытая или неактивная вкладка, меню, диалог и ручная пауза останавливают симуляцию. Догоняющего расчёта, офлайн-дохода, рекламы и режима фарма нет. Аварийное закрытие может откатить только к последнему удачному снимку. Повреждённые данные не удаляются молча: доступно скачивание копии, затем отдельное подтверждение сброса.

Web Locks разрешает запись только одной вкладке игры. Для запуска нужен современный браузер с WebGL2 и Web Locks, HTTPS (либо localhost). Прогресс не переносится между устройствами и может быть потерян при очистке данных сайта.

## Архитектура

- `src/game.ts`: чистая детерминированная симуляция, 30 тиков/с, экономика, волны, развитие и проверка снимков
- `src/scene.ts`, `src/oplotModels.ts`: Three.js-сцена, локальные GLB, пулы моделей и снарядов, эффекты, ортографическая камера и процедурный резерв
- `src/enemyModels.ts`, `src/enemyAnimation.ts`: резервные геометрии и позы, а также визуальные импульсы, синхронизированные с фазами атак
- `src/scene.ts`: разрушенный город с песком вместо дорог: дюны частично закрывают два автобуса и нижние этажи. Модели tevy загружаются локально. Мягкие тени от геометрии используют одну карту 1024×1024, обновляемую не чаще 30 раз в секунду.
- `src/spawnGeometry.ts` и `src/viewport.ts`: фиксированная окружность появления и камера с постоянной шириной мира
- `src/main.ts`, `src/style.css`: русскоязычный адаптивный HUD, мастерская, результаты и управление
- `src/persistence.ts`: атомарная запись, backup, блокировка вкладок и причины паузы
- `src/platform.ts`: локальный адаптер жизненного цикла и mock рекламы; это не интеграция с Яндекс Играми
- `src/audio.ts`: короткие синтезированные эффекты без внешних файлов

## Баланс прототипа

Конфиги и цены находятся в game.ts. Боевые ветки ограничены 15 уровнями, постоянные — 10. Каждый тип рядовых мехов начинает с 10 HP на своей первой волне и получает +1 HP за каждую следующую. Урон по-прежнему растёт на 6% от базы за волну. У Колосса 624 HP. Главный периметр появления имеет радиус 12; обычные мехи прикрытия появляются чуть ближе, на 10,45. Каждому появлению предшествует предупреждение на 0,5 с. Рывки появляются с волны 4, Стрелки — с волны 6. На волнах 1–29 остаётся 18–63 врага. На первой волне первые пять мехов выходят по одному, затем группы, на остальных обычных волнах группы по 3–7 с разных сторон. Со второй волны базовая пауза между группами 2,15 с и постепенно сокращается до 1,45 с; ограничение на число мехов на арене может задержать следующий выход. На волне 30 по-прежнему только Колосс. Светлая окружность показывает дальность огня турели: 7,5 единицы.

У каждого типа своя атака: Штурм выдвигает поршневой кулак, Рывок делает выпад клинками, Стрелок закрепляется на четырёх опорах и стреляет с отдачей. Стрелок останавливается ровно на границе дальности турели (7,5), и турель может в него стрелять. С ним одновременно, чуть впереди и по бокам, появляются обычные мехи; автонаведение предпочитает ближайших. Параметры Стрелка: 10 HP при первом появлении, базовый урон 5, скорость 2 и цикл 3,2 секунды. Снаряд летит со скоростью 6 и наносит урон один раз при попадании. Уже выпущенный снаряд остаётся опасным после уничтожения Стрелка, поэтому волна заканчивается после его разрешения. Колосс проводит два последовательных удара по 21 урона за цикл 2 секунды. Замах, удар и восстановление хранятся в состоянии игры; скрытие вкладки, меню и загрузка не пропускают эти фазы.

На телефоне сцена занимает всю ширину между отдельными верхней и нижней панелями. Ширина мира в камере постоянна — 21,3 единицы; камера смотрит вниз под углом около 31°, а вертикальный обзор зависит от высоты оставшегося места. Пропорции моделей не растягиваются. Для чёткости 3D-сцена использует плотность экрана до DPR 2. На широком компьютере поле центрируется, чтобы обзор по вертикали оставался удобным. Размер окна и DPR не меняют точки появления, дистанции и время волн при одинаковом seed и одинаковых покупках. Старые сохранения переходят на окружность один раз: дальние живые мехи перемещаются на радиус 12 с сохранением HP, ближайшее предупреждение сокращается до 0,5 секунды, остальные ещё не появившиеся враги возвращаются в обычную очередь. Старые забеги продолжаются с новой скоростью, а закрытые волны не повторяются. Валюты, покупки и уже выданные награды сохраняются.

Волны рассчитаны на усиленный натиск; победа без постоянных улучшений не гарантируется.

## GitHub Pages

`vite.config.ts` задаёт base `/Mech-idle/`. Workflow `.github/workflows/pages.yml` устанавливает зафиксированные зависимости, запускает тесты и production-сборку, затем публикует `dist` через GitHub Pages. В Settings → Pages источником должен быть выбран GitHub Actions. Deploy-job получает только `pages: write` и `id-token: write`; build-job имеет `contents: read`.

При переименовании репозитория измените Vite base. Никаких токенов или секретов клиентской сборке не требуется.

## Границы этой версии

- Упрощённые процедурные модели по утверждённым силуэтам: бронированный Штурм, тонкий Рывок с клинками, четырёхногий Стрелок и широкий Колосс. За радиусом 15 расположены 87 декоративных объектов: промышленные руины, контейнеры, баки, трубы, останки мехов и сухая растительность; они не участвуют в коллизиях
- Без реального платформенного SDK, облачных сохранений, рекламы, IAP, аналитики, PvP и сервера
- Реальные Android/iOS-устройства, FPS и длительный GPU-прогон ещё нужно проверить; автоматические тесты не заменяют эти проверки
- Локальное сохранение защищает от обычных ошибок и повторных событий, но не от намеренного редактирования данных владельцем браузера
- Источники и лицензии зависимостей: [ASSET_PROVENANCE.md](ASSET_PROVENANCE.md). Условия оригинальных файлов: [LICENSE](LICENSE)

Изолированная страница `ui-review.html` показывает те же UI-компоненты и изображения без запуска WebGL, симуляции или сохранений; она нужна для визуальной проверки размеров.

Подробный протокол текущих проверок: [VERIFICATION.md](VERIFICATION.md).

Проверка точной геометрии и поз без WebGL: `node scripts/render-enemy-review.mjs artifacts/enemies-3d-review.svg`. Этот CPU-рендер не подтверждает качество GPU-освещения или FPS. Для PNG можно открыть SVG в Inkscape и экспортировать его; приложение игры от Inkscape не зависит.
