# ОПЛОТ — Турель и мехи

Играбельный 3D-прототип защиты неподвижной турели: 30 волн, случайные направления атак, два типа обычных мехов и финальный Колосс. Турель стреляет сама; игрок управляет улучшениями.

[Играть в браузере](https://staburovalexey.github.io/Mech-idle/) · [Репозиторий](https://github.com/StaburovAlexey/Mech-idle)

## Запуск

Нужен Node.js 24 и npm.

```sh
npm ci
npm run dev
```

Откройте адрес Vite с путём `/Mech-idle/`.

```sh
npm run test    # логические регрессии, сохранения и паузы
npm run build   # строгая проверка TypeScript + production-сборка
npm run check   # все проверки
npm run preview
```

## Как играть

- Нажмите «Новый забег». Прицеливание и огонь автоматические
- За обычного меха: 3 золота; за быстрого: 4; за Колосса: 50
- Четыре боевых модуля покупаются за золото: урон, максимальные HP, темп стрельбы и ремонт
- Купленный за золото модуль действует сразу, в том числе между волнами и на ручной паузе. Урон новых выстрелов меняется сразу; уже летящие снаряды сохраняют урон. Темп пропорционально сокращает оставшееся ожидание выстрела, без бесплатного выстрела
- Здоровье переносится между волнами. Покупка максимальных HP повышает потолок, но не лечит. Ремонт действует только во время боя и короткого перехода
- Каждая полностью пройденная волна даёт 1 кристалл. В мастерской кристаллы усиливают стартовые параметры будущих забегов
- Поражение и победа завершают забег. Золото и боевые модули сбрасываются; кристаллы и мастерская сохраняются
- На волне 30 появляется только Колосс. После его поражения наступает победа; волны 31 нет

Во время боя верхняя панель ресурсов и нижняя панель четырёх улучшений занимают отдельные строки. 3D-поле находится между ними: панели его не перекрывают. Кнопка «Меню» открывает управление, звук, правила, сохранение/выход и подтверждаемое завершение забега. Открытое меню останавливает бой; его закрытие не снимает отдельную ручную паузу.

Касания и мышь: кнопки интерфейса. Клавиши `1`–`4`: купить соответствующий модуль. `Пробел`: ручная пауза, когда фокус не на кнопке. `Escape`: открыть или закрыть меню боя; в диалоге отменяет закрытием. Кнопки поддерживают обычную клавиатурную навигацию. Звук включается отдельно кнопкой ♪ и генерируется в браузере.

## Сохранение и отсутствие

Снимок профиля и активного забега хранится одним объектом в localStorage этого браузера, вместе с проверенной предыдущей копией. Сохраняются RNG, враги, снаряды, покупки, дробные HP и оплаченные награды. Перезагрузка открывает меню с кнопкой продолжения. Если старое сохранение содержит оплаченные, но ещё не включённые модули, при загрузке они включаются один раз, без повторной оплаты и лечения.

Скрытая или неактивная вкладка, меню, диалог и ручная пауза останавливают симуляцию. Догоняющего расчёта, офлайн-дохода, рекламы и режима фарма нет. Аварийное закрытие может откатить только к последнему удачному снимку. Повреждённые данные не удаляются молча: доступно скачивание копии, затем отдельное подтверждение сброса.

Web Locks разрешает запись только одной вкладке игры. Для запуска нужен современный браузер с WebGL2 и Web Locks, HTTPS (либо localhost). Прогресс не переносится между устройствами и может быть потерян при очистке данных сайта.

## Архитектура

- `src/game.ts`: чистая детерминированная симуляция, 30 тиков/с, экономика, волны, развитие и проверка снимков
- `src/scene.ts`: Three.js-сцена, процедурные модели, инстансинг, эффекты, окружность дальности и ортографическая камера
- `src/spawnGeometry.ts` и `src/viewport.ts`: фиксированная окружность появления и камера с постоянной шириной мира
- `src/main.ts`, `src/style.css`: русскоязычный адаптивный HUD, мастерская, результаты и управление
- `src/persistence.ts`: атомарная запись, backup, блокировка вкладок и причины паузы
- `src/platform.ts`: локальный адаптер жизненного цикла и mock рекламы; это не интеграция с Яндекс Играми
- `src/audio.ts`: короткие синтезированные эффекты без внешних файлов

## Баланс прототипа

Конфиги и цены находятся в `game.ts`. Боевые ветки ограничены 15 уровнями, постоянные — 10. HP обычных врагов растут на 10% от базы за волну, урон — на 6%. Все мехи, включая босса, появляются на окружности радиуса 12 игровых единиц вокруг турели. Направление случайное, с ограничением двух подряд в одном из 12 угловых сегментов. Появление может быть видно на экране; короткое предупреждение длится 0,5 секунды. Долгого ожидания за кадром нет. Быстрые мехи появляются с волны 4. Светлая окружность на земле показывает настоящий радиус огня — 10 единиц; турель не выбирает цели за его пределами. Скорости движения сохранены.

На телефоне сцена занимает всю ширину между отдельными верхней и нижней панелями. Ширина мира в камере постоянна — 24,7 единицы; вертикальный обзор зависит от высоты оставшегося места. Пропорции моделей не растягиваются. На широком компьютере поле центрируется, чтобы обзор по вертикали оставался удобным. Размер окна и DPR не меняют точки появления, дистанции и время волн при одинаковом seed и одинаковых покупках. Старые сохранения переходят на окружность один раз: дальние живые мехи перемещаются на радиус 12 с сохранением HP, ближайшее предупреждение сокращается до 0,5 секунды, остальные ещё не появившиеся враги возвращаются в обычную очередь. Валюты, покупки и уже выданные награды сохраняются.

Контрольный путь без постоянных улучшений: поддерживать ремонт на уровне `floor(номер волны / 4)`, остальные покупки чередовать между уроном и темпом стрельбы, накапливая на выбранную ветку. Автотест проверяет победу на seed 1, 3, 17, 42 и 2026; seed 42 также проходит сохранение/загрузку на каждой волне. Это техническая проверка достижимости, а не завершённый пользовательский плейтест.

## GitHub Pages

`vite.config.ts` задаёт base `/Mech-idle/`. Workflow `.github/workflows/pages.yml` устанавливает зафиксированные зависимости, запускает тесты и production-сборку, затем публикует `dist` через GitHub Pages. В Settings → Pages источником должен быть выбран GitHub Actions. Deploy-job получает только `pages: write` и `id-token: write`; build-job имеет `contents: read`.

При переименовании репозитория измените Vite base. Никаких токенов или секретов клиентской сборке не требуется.

## Границы этой версии

- Низкополигональные процедурные модели и открытая постапокалиптическая местность: разрушенная дорога, трещины, ржавый лом и сухая растительность
- Без реального платформенного SDK, облачных сохранений, рекламы, IAP, аналитики, PvP и сервера
- Реальные Android/iOS-устройства, FPS и длительный GPU-прогон ещё нужно проверить; автоматические тесты не заменяют эти проверки
- Локальное сохранение защищает от обычных ошибок и повторных событий, но не от намеренного редактирования данных владельцем браузера
- Источники и лицензии зависимостей: [ASSET_PROVENANCE.md](ASSET_PROVENANCE.md). Условия оригинальных файлов: [LICENSE](LICENSE)

Изолированная страница `ui-review.html` показывает те же UI-компоненты и изображения без запуска WebGL, симуляции или сохранений; она нужна для визуальной проверки размеров.
